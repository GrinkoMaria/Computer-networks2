# Домашние задания по курсу "Компьютерные сети"

1. Задание 1. 5 примеров по модели OSI — Здесь мы писали какие 5 ошибок могут случится на разных уровнях модели OSI.
2. Задание 2. Ethernet in Wireshark — Фотография Ethernet в Wireshark.
3. Задание 3. Первая работа с Cisco — Разбили сеть на пять подсетей и выполнили эту настройку в Cisco.
4. Задание 4. Схемы_Гринько (1) — Схема MAC-адреса и схема соединения компьютеров через коммутатор.
5. Задание 5. Схема сети — Настройка и проверка сети.
6. Задание 6. Блокировка Cisco в брандмауэр.
7. Задание 7. Решение задач — Решение задач по IP-адресации и маскам подсети.
8. Задание 8. Схемы в Cisco — Создание трёх схем в Cisco Packet Tracer.
9. Задание 9. Третья схема — Настройка третьей схемы через RIP.
10. Задание Я.10. Протокол DHCP — конспект по презентации протокол DHCP.
11. Настройка схемы сети с использованием технологий NAT/PAT (статический и динамический NAT).
12. Настройка DNS-сервера в Cisco Packet Tracer.
13. Краткая выжимка из трёх презентаций по TCP и UDP.
14. Анализ пакетов TCP и UDP в Wireshark. Скриншоты с флагами TCP (SYN, ACK) и примером UDP-пакета.
15. Основы HTTP/HTTPS — Определения терминов, разбор запросов и ответов, составление HTTP-запросов.
